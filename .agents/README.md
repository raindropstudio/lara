# 에이전트 자료

이 폴더에는 벤더 중립적인 반복 작업 자료를 둔다. 지속적인 프로젝트 맥락은 `docs/`, 실행 로직은 저장소 도구에 둔다.

Nexon fixture 기록이나 원본 스키마 변경 대응처럼 반복할 작업에만 skill을 만든다. skill은 로직을 설명문으로 복제하지 않고 재현 가능한 저장소 명령을 호출한다.

임시 작업 기록과 대화는 Git에서 제외된 `.agents/runs/`에 둔다.

## 작업별 스킬

- [lara-web-check](skills/lara-web-check/SKILL.md): 캐릭터 조회·군장검사 화면의 부분 응답과 반응형을 브라우저에서 검증할 때 사용한다.

이 목록을 저장소 스킬의 진입점으로 사용한다. 에이전트가 스킬 폴더를 자동 발견하지 못해도 해당 `SKILL.md`를 읽어 적용할 수 있다. 실행 명령은 운영 문서와 도구에 두고 스킬에는 검증할 판단 기준만 남긴다.
