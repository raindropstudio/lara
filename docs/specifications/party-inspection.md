# 군장검사

[Notion 파티검색 메모](https://www.notion.so/ce0fb5e46878411ca94e4a9ce5cc1f68)와 [Figma 군장검사 화면](https://www.figma.com/design/EnWT6VTeCpaKG5ZKgKK6rS/lara.moe?node-id=1509-84)을 참고한다. Figma는 화면 참고 자료이며 별도 디자인 시스템을 도입하지 않는다.

## 입력과 조회

- `/inspection`에서 쉼표·공백·줄바꿈으로 구분한 최대 6명의 캐릭터를 추가한다. 중복은 합치고 빈 입력·잘못된 이름·인원 초과는 요청 전에 안내한다.
- 캐릭터 검색과 같은 밑줄형 `UiNicknameInput`을 사용한다. 캐릭터 추가·삭제·좌우 이동·개별 갱신·전체 갱신을 지원한다.
- 기존 캐릭터 GET과 수집 POST/SSE 계약을 사용한다. 저장된 값을 먼저 표시하며, 마지막 수집일이 KST 기준 이전 날짜라면 자동 갱신한다. Nexon 원본의 기준 날짜와 마지막 수집 시각을 구분해 같은 오래된 기준 자료를 반복 수집하지 않는다.
- 캐릭터별 성공과 실패를 분리한다. 갱신 실패 시 기존 자료와 오류를 함께 표시한다. 삭제·화면 이탈 시 요청을 취소하고, 수집 대기는 2분으로 제한한다. 취소는 클라이언트 대기 종료이며 서버의 공유 수집 작업을 취소하지 않는다.

## 비교

- 캐릭터는 테두리 없는 열로 나란히 배치하고, 중앙 항목명 아래에 전투력·주스탯·방무·유니온 순서로 수치를 표시한다. 전투력과 주스탯은 만·억 단위로 줄여 표시하며 원래 수치는 툴팁에 둔다. 시드링과 훈장·칭호는 아이콘으로 비교하고, 나머지 능력치와 스킬 요약은 펼쳐 본다.
- 레벨, 전투력, 보스 데미지, 방무, 크리티컬 확률·데미지, 스타포스, 아케인·어센틱포스, 유니온을 비교한다. 누락된 값은 `—`로 표시하고, 유효한 값이 둘 이상인 수치의 최고값을 강조한다.
- 주스탯은 AP 배분으로 추정한다. 제논의 MIX는 기획 메모에 따른 `(STR + DEX + LUK) × 0.66` 비교 지표이며 데몬어벤져는 제공된 HP를 사용한다. 스탯 영역이 불완전하거나 AP 배분이 없으면 추정하지 않는다.
- 현재 착용 장비와 칭호·특수 장비를 프리셋 번호로 조회한다. 시드링 레벨, 어빌리티·하이퍼스탯 활성 프리셋, 장착 V·특수 코어, 솔 야누스를 제외한 HEXA 코어, 현재 링크스킬을 요약한다. 장비를 클릭하거나 키보드로 열면 잠재·에디셔널 옵션을 확인한다.
- 시드링 누락은 정상 수집한 활성 장비에만 안내한다. 확인된 장비·칭호·전투복 옵션 만료와 길드 미가입을 표시한다. 부분 응답을 미착용이나 부적절한 세팅으로 단정하지 않는다.
- 넓은 화면은 비교표, 640px 미만은 캐릭터별 보기가 기본이며 사용자가 전환할 수 있다. 캐릭터와 비교표는 같은 영역에서 가로 스크롤해 열을 맞추고, 페이지 전체에는 가로 스크롤이 생기지 않게 한다.

## 판정 범위

메모의 길드 스킬, 유니온 프리셋·아티팩트 활성 여부, 직업별 파티 시너지와 사냥 프리셋 판정은 현재 수집 계약에서 충분히 확인할 수 없다. 직업별 최대 강화 목록도 검증되지 않아 V·HEXA의 전체 강화율 대신 확인된 코어 정보를 보여준다. 이 항목들은 별도 수집·규칙 검증이 필요하며 임의의 추천 점수나 보스 합격 판정을 만들지 않는다.
